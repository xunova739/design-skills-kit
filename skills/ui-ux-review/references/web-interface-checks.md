# Web 实现检查：按场景取证

仅在有 Web 源码或可运行页面、且需要定位实现问题时读取。沿用主入口的证据边界与严重度；静态规则命中先作为线索；代码可直接证明的缺陷须说明推导依据，不能冒充已观察到的运行结果。按当前任务选择相关项，无关项写“不适用”。

## 语义、键盘与焦点

- 操作用原生 button，导航用真实链接；图标按钮有可理解名称，表单有标签，装饰图像不制造读屏噪声。原生控件已有键盘行为，不为通过检查强加重复 onKeyDown/onKeyUp。
- 实测 Tab 顺序、Enter/Space、链接新标签操作；自定义控件按其角色验证键盘行为。检查焦点可见且未被粘性头部、弹层或底栏遮挡。
- 异步反馈需要适当的读屏通知；普通状态可用 polite，紧急错误按语义选择，不把所有消息机械替换成同一种 live region。
- 证据：控件语义/可访问名称、键盘操作结果、焦点状态截图；只有截图不能证明键盘或读屏可用。窄视口只验证排版；触摸/拖动还需独立操作证据，并注明真实设备或浏览器模拟。

## 文字对比度

- 普通文字至少 4.5:1；大字可 3:1。大字为 18pt 常规（24 CSS px）或 14pt 粗体（约 18.67 CSS px），中日韩文字参照相当字号。**18px 常规文字不属于这个大字门槛。**
- 依据实际前背景颜色、计算字号与字重测量；渐变/图片背景检查最不利位置。结果不向上四舍五入；不要仅凭截图观感放行。
- 标签、占位、帮助和错误文字也需检查；非文本控件按相应标准判断，不混用文字门槛。停用控件、标志等例外需说明，不扩展为品牌色通用豁免。
- 证据：颜色、字号、字重、比值与对应状态；不是完整 WCAG 合规声明。

## 表单、失败与恢复

- name、type、inputmode、autocomplete 匹配字段语义；允许粘贴，标签与控件关联。不要为了规避密码管理器而默认关闭所有非认证字段自动填充。
- 错误在相关字段附近解释原因和下一步；提交失败保留输入，合理定位首个错误，允许重试。请求中防重复提交，权限或前置条件导致禁用时说明原因。
- 未保存内容离开页面的保护按丢失风险选择；已有自动保存时先验证保存/恢复，不叠加无必要确认。
- 证据：粘贴、自动填充、校验、失败/重试、返回/刷新后的字段值；检查恢复是否造成重复操作。

## 内容、图片与布局

- 用空值、超长中文、长英文标识和长用户输入检查断行/截断。截断不能隐藏完成主任务必需的信息；flex 子项必要时允许收缩。
- 图片预留尺寸或稳定比例，关键首屏图与屏下图采用合适加载策略；窄屏、放大、缺图状态不遮挡主操作。
- 先修溢出根因，不用 overflow-x-hidden 掩盖消失的内容或焦点；全屏移动布局按需检查安全区。
- 证据：指定视口和内容样本的截图、布局偏移记录、图片失败后的可用性。

## 动效与性能

- 尊重 reduced motion，动画可被操作打断；自动持续动效需要适当暂停/停止机制。优先成本低的动画属性，避免无意 transition: all；其他动画按设备测量判断。
- 大列表先测滚动、筛选输入与 DOM 成本，再选分页/搜索/虚拟化。超过 50 条不是强制虚拟化阈值，也不是新增依赖的授权。
- 记录测量环境、操作、结果和限制。实验室单次结果不能冒充真实用户分位值；没有测量就写“未验证”，不写“性能应该达标”。
- 证据：普通/减少动效模式、键盘输入响应、性能轨迹或适用测试结果；检查优化未破坏浏览器查找、键盘和阅读顺序。

## 状态、主题与本地化

- 筛选/分页等需要分享或返回恢复的状态可同步 URL；敏感输入、草稿和瞬时状态不能一律入 URL。删除等破坏性操作选择确认或可验证的撤销。
- 主题按产品要求检查，涉及暗色时验证原生控件、color-scheme、状态对比度；不强制为所有页面新增双主题。
- 日期、金额和数字按产品 locale/时区契约格式化，可用 Intl；显式用户偏好优先，不能仅按 IP 猜语言。SSR 同时检查初始时间/语言是否产生 hydration 差异。
- 中文检查标点、混排、断行与可读性；不强制英文 Title Case、&、固定人称。品牌/标识是否禁止自动翻译按真实命名规范决定。
- 证据：重载/返回/分享后的状态，语言/时区样例，服务端与客户端首屏，原生控件实际颜色。
