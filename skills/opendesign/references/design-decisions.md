# Direction and targeted refinement

Read for a substantial new surface or when an interface needs more than a small correction.

## Choose based on the task

Record briefly: audience, primary action, factual content, authoritative existing visual choices and open choices. A product's marketing page and admin screen need different treatment even with shared tokens.

- Persuasion: clarify the offer, differentiator and next action. Use truthful proof when available.
- Operations: prioritize scanability, familiar controls, density, state and recovery. Quiet treatment can be correct.
- Reading: create reading order, comfortable lines, headings and navigation. Avoid breaking an argument into decorative cards.
- Showcase: let the work/argument dominate; chrome supports it.

Choose an organizing idea specific to the subject. If it transplants unchanged to an unrelated client, reconsider before polishing. Familiar patterns can still be right for familiar tasks; novelty is not an acceptance condition.

## Refinement versus replacement

Refinement retains working conventions, brand, factual copy and behavior outside the diagnosed issue. A requested redesign retains product truth/functions while choosing a coherent replacement direction. A spacing fix is not a rebrand.

When alternatives resolve a real decision, sketch distinct structures before detailed implementation. Do not automatically generate image comps, run random seeds, add effects or demand plan approval for an authorized task.

## Match intervention to evidence

| Observed problem | Intervention | Verify afterward |
|---|---|---|
| Main action/reading order lost | Hierarchy, grouping, labels, placement | Locate and complete intended task |
| Dense content hard to scan | Alignment, spacing, grouping, numeric columns | Long real data at relevant widths |
| Repeated components inconsistent | Normalize tokens and states | Compare same-state components |
| Brand absent/page generic | Strengthen one subject-specific idea | Brief fit and comprehension |
| Effects compete with task | Reduce nonessential motion/decoration | Focus, reading, reduced motion |
| Failure strands user | Explanation, correction/retry, retained input | Trigger failure, complete recovery |
